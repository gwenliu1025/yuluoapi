# 雨落 API 默认首页品牌化实施计划

## 目标

仅替换默认 `/home` 的展示内容，保留自定义 HTML/URL 首页、简洁首页、后台配置优先级、登录态跳转和其他路由。视觉目标以用户确认的“雨后青瓷”截图为准。

## 任务 1：测试锁定行为边界

- 为默认首页新增组件测试，先验证新品牌文案、CTA、精选模型区和末尾小字行移除。
- 保留并扩展简洁首页测试，证明 `home_content` 与 `compact_home_enabled` 分支不受影响。
- 为雨滴动效新增测试，覆盖减少动态效果和组件卸载清理。

## 任务 2：实现默认首页

- 仅替换 `HomeView.vue` 的默认 `v-else` 分支。
- 上半区只包含顶部导航、品牌主标题、副标题、品牌母题、两个 CTA 和雨后背景；不展示浮动模型图标。
- 下半区保留全宽留白底板，展示带准确品牌标志的 DeepSeek、智谱 GLM、Kimi、Qwen，以及“更多国产模型 / 查看全部模型”。
- 删除精选模型区下面原有的品牌、GitHub、条款等最末小字行。
- 主 CTA 未登录时进入 `/login`，已登录时进入对应控制台；次 CTA 进入 `/model-plaza`。

## 任务 3：实现克制自然动效

- 使用 GSAP 编排少量雨滴落下和涟漪扩散，只动画化变换与透明度。
- 页面离屏或不可见时暂停，组件卸载时完整清理。
- 移动端降低动画数量；`prefers-reduced-motion` 下停用循环动效。

## 任务 4：固化项目文档

- 新增根级 `AGENTS.md`，要求每次新任务先读 `CURRENT_STATE.md`，再按任务类型选择对应规格或 OpenSpec。
- 新增首页品牌设计规格，记录范围、文案、视觉、动效和不可改边界。
- 更新 `CURRENT_STATE.md` 并新增日期化验证证据。

## 验证

- `pnpm test:run`
- `pnpm typecheck`
- `pnpm lint:check`
- `pnpm build`
- `git diff --check`
- 在 1440×1024 与 390×844、浅色与深色状态下进行浏览器交互和视觉对照。
- 项目根目录 `design-qa.md` 的最终结果必须为 `passed`。

## 不执行

- 不修改后端 API、数据库、控制台或管理后台。
- 不提交、推送、发布或部署。
