# 雨落 API 默认首页品牌设计规格

> 状态：已获用户确认
>
> 日期：2026-08-27
>
> 适用范围：默认 `/home` 展示分支

## 1. 目标

将默认 `/home` 改造为“雨后青瓷”视觉方向的雨落 API 品牌首页，以克制、自然的雨滴与涟漪建立品牌识别，并用清晰的双 CTA 和国产模型展示完成主要访问路径。

本次只替换默认首页的展示内容，不改变首页配置体系、其他路由、控制台、管理后台或后端行为。

## 2. 首页分支与配置优先级

现有首页分支和优先级必须保持不变：

1. 配置了 `home_content` 时，优先展示自定义首页；URL 继续使用 iframe，HTML 继续按现有方式渲染。
2. 未配置 `home_content` 且启用 `compact_home_enabled` 时，继续展示简洁首页。
3. 只有前两项均不生效时，才展示本规格定义的默认 `/home`。

自定义 HTML/URL 首页和简洁首页继续保留运行时 `siteName`、`siteSubtitle` 及其既有配置语义。默认 `/home` 固定使用本规格的品牌文案，不得让品牌改造反向覆盖前两种首页模式。

## 3. 固定品牌文案

默认 `/home` 必须逐字使用以下内容：

- 主标题：**雨落 API**
- 副标题：**企业级 API 服务网关**
- 品牌母题：**世上没有两场相同的雨，也没有一个模型适合所有问题。雨落，让每个问题遇见合适的中国模型。**

不得缩写、改写或用运行时站点标题替换这三项文案。

## 4. 页面结构

### 4.1 上半区

上半区包含顶部导航、固定品牌文案、两个 CTA 和雨后氛围背景。

- 顶部导航保留站点标志及现有可用的语言、文档、主题和登录态入口能力。
- 主视觉以主标题、副标题和品牌母题形成明确层级。
- 上半区不得出现浮动模型图标、环绕模型徽标或以模型 Logo 作为漂浮装饰。
- 主 CTA 根据登录态工作：未登录进入 `/login`，已登录进入对应控制台。
- 次 CTA 文案为“模型广场”，进入 `/model-plaza`。

### 4.2 下半区

下半区使用全宽、留白充足的底板承接模型展示，与上半区雨后氛围形成清晰但自然的分区。

- 展示 DeepSeek、智谱 GLM、Kimi、Qwen。
- 四个模型必须使用各自原品牌标志，不得用首字母、通用占位图形或自绘近似图标替代。
- 提供“更多国产模型 / 查看全部模型”入口，并指向 `/model-plaza`。
- 只移除该模型展示区下方最末的小字行；不得借此删除自定义首页、简洁首页或其他页面的页脚与信息。

## 5. 视觉与动效

- 视觉基调为“雨后青瓷”：清润、留白、安静、有自然湿润感，不使用喧闹的霓虹、密集粒子或夸张漂浮装饰。
- 雨滴与涟漪必须克制、自然，承担氛围和品牌识别，不得遮挡文案、CTA 或模型信息。
- 循环动效优先只改变 `transform` 与 `opacity`，避免持续触发布局计算。
- 页面离屏或不可见时暂停循环动效，组件卸载时清理动画实例、监听器和定时资源。
- 移动端降低雨滴、涟漪数量和运动复杂度，优先保证文字、按钮和模型入口清晰可用。
- `prefers-reduced-motion: reduce` 下停用循环雨滴与涟漪动效，保留完整静态内容和导航能力。

## 6. 行为与范围边界

本次允许修改的业务范围仅为默认 `/home` 展示分支及其直接使用的前端样式、资源和测试。

以下内容不得改变：

- 自定义 HTML/URL 首页的渲染方式；
- 简洁首页的结构、配置语义和登录入口；
- `home_content`、`compact_home_enabled` 等后台配置优先级；
- `/login`、控制台、`/model-plaza` 及其他路由的既有页面行为；
- 后端 API、数据库、鉴权、计费、渠道、模型广场数据协议和管理配置；
- 其他前台页面、控制台和管理后台的视觉与功能。

## 7. 验收条件

- 默认 `/home` 准确展示三项固定品牌文案，且上半区没有浮动模型图标。
- 未登录和已登录状态下，主 CTA 分别进入登录页和对应控制台；次 CTA 进入模型广场。
- 下半区以全宽留白底板展示带原品牌标志的 DeepSeek、智谱 GLM、Kimi、Qwen，并提供更多模型入口。
- 模型展示区下方只移除最末小字行，没有影响其他首页模式或其他页面。
- 自定义 HTML、URL 首页、简洁首页及其配置优先级通过回归验证。
- 桌面端与移动端内容均可读可操作；减少动态效果偏好生效，循环动效具备暂停与清理机制。
- 没有后端或其他页面的范围外变更。
